// architecture

Fifteen apps don't get built fifteen times.

Shared code lives in packages. The apps bring their own identity.

Passion Gym own theme
Revolt own theme
Techne own theme

one shared foundation

internal packages
  • networking
  • auth + token refresh
  • navigation
  • forms & lists
  • financial flows
  • localization
  • DI contracts

No package knows what colour it is. Each app injects its own theme, so the same widgets ship seven identities.

reuse

Written once

Networking, auth, navigation, widgets, whole feature modules — consumed from packages, never copied between projects.

theming

Anonymous by design

Colours, type, and assets are declared by the app and resolved at runtime. A new brand is configuration, not a fork.

i18n

Localized from day one

Strings live with the package that owns them, and layouts are direction-aware — so Arabic mirrors, not just translates.

coupling

Dependencies point inward

Shared pages declare contracts; each app injects its own implementation through GetIt. That's what stops a package marrying its host.

// how the work happens

Requirement to store listing, then back again.

I own more of this cycle than a typical mobile role — and it's a cycle, not a line.

  1. 01

    Gather the requirement

    Stakeholders internally, clients directly for real estate. What people ask for and what they need are often different things.

  2. 02

    Structure the work

    Turn it into concrete tasks, and agree the API contract with backend so the data matches the screen.

  3. 03

    Design the UI/UX

    Designed by me, using AI-assisted workflows and research. B2B admin tools and B2C member apps get different treatment.

  4. 04

    Build

    Against the shared packages — extending them when the feature is general, keeping it local when it isn't.

  5. 05

    Launch

    Through review and out to both stores, including the parts that aren't code.

  6. ↻

    Back to the client

    Bugs and enhancement requests from real users, triaged and fed back in. Shipping restarts the conversation.

  7. returns to 01
