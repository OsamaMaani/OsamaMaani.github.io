Six products built on shared infrastructure. Each one gets its own domain model and workflows; none of them re-implements navigation, networking, theming, or state plumbing.

HR

Technia ESS

A legacy Flutter codebase refactored into scalable MVVM, then extended.

  • Salary management
  • Request workflows end to end

Real estate

Technia Real Estate

A sales platform for property teams, tuned for long lists and frequent updates.

  • Leads, follow-ups, actions, and deals
  • Performance work on list rendering and state
  • Requirements gathered direct from clients

Fitness

Technia Gyms

Built from scratch, architected so new membership products drop in cleanly.
